# 審核用測試帳號（金流審核補件用）

> 對應藍新金流審核說明第 3 點：「請提供測試帳號及密碼至藍新客服信箱」。

## 一、為什麼需要兩組帳號

Twogether 是**情侶共用**的服務：Premium 會員以「一對情侶」為計費單位，
因此 App 內的「升級 Premium」必須在**完成配對**後才會開放付款。
單一帳號會停在「尚未配對」的提示畫面，審核人員無法走完付款流程。

`scripts/create-review-account.js` 因此會一次建立**兩個已互相配對的帳號**，
兩者密碼相同，審核人員用主帳號登入即可直接看到方案並付款。

## 二、產生（或輪換）測試帳號

於正式環境設定好 `DATABASE_URL` 後執行：

```bash
# 自動產生一組隨機密碼並印出
npm run seed:review-account

# 或指定密碼
REVIEW_ACCOUNT_PASSWORD='YourStrongPassword' npm run seed:review-account
```

腳本特性：

- **可重複執行**：帳號已存在時只重設密碼並確認配對狀態，不會產生重複資料。
  審核結束後再跑一次即可**輪換密碼**，等同停用舊密碼。
- 兩個帳號皆標記為已驗證信箱，登入後不會出現驗證提醒。
- 會植入 3 筆「審核測試資料」紀錄，讓審核人員一登入就看得到實際畫面，而非空白 App。
- 兩個帳號皆為**免費方案**，因此可以完整體驗「免費 → 付款 → 開通 Premium」的全流程。

預設帳號（可用環境變數 `REVIEW_ACCOUNT_EMAIL` / `REVIEW_PARTNER_EMAIL` 覆寫）：

| 用途 | 帳號 |
| --- | --- |
| 主帳號（請審核人員使用） | newebpay-review@twogether.fun |
| 配對夥伴帳號 | newebpay-review-partner@twogether.fun |

## 三、提供給審核人員的操作說明（可直接貼進客服信）

```
測試網址：https://twogether.fun
測試帳號：newebpay-review@twogether.fun
測試密碼：（請填入 npm run seed:review-account 產生的密碼）

操作步驟：
1. 開啟 https://twogether.fun ，以上述帳號密碼登入。
2. 點右上角頭像 →「升級 Premium」，即可看到 30／90／365 天三種方案。
   （亦可直接瀏覽免登入的公開商品頁 https://twogether.fun/pricing ）
3. 付款方式可選擇「藍新金流 NewebPay」，如需報帳可展開「需要收據抬頭或統一編號？」填寫。
4. 點選任一方案的「升級」，系統會導向藍新金流付款頁。
5. 完成付款後將自動導回本站結果頁，Premium 權益即時生效，
   系統同時開立電子收據並寄送至帳號信箱。
6. 收據可於「升級 Premium →購買紀錄與收據」查看、列印或存成 PDF。

備註：
・最低方案為 NT$90，如需實際刷卡驗證，完成後可來信申請全額退款。
・亦可選擇「ATM 虛擬帳號」或「超商代碼」取號，即可驗證取號流程而不需實際付款。
・本服務為一次性買斷制，不會自動續訂或自動扣款。
```

## 四、安全注意事項

- 測試帳號密碼僅透過金流平台的官方客服信箱提供，勿公開張貼。
- 審核通過後請重新執行腳本輪換密碼。
- 測試帳號與一般使用者權限相同，**沒有任何後台或管理權限**
  （後台 `/admin` 另以 `ADMIN_PASSWORD` 保護，不提供給審核人員）。
